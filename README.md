# 📰 NewsR - First React Project

NewsR is a modern and responsive news web application built using React.js.  
It allows users to browse the latest news and explore different news categories through a clean and user-friendly interface.

## 🚀 Features

- 📰 Latest News
- 🌍 Category-wise News
- 📱 Fully Responsive Design
- 🖼️ News Images with Fallback Image
- 🔗 Read More option for full articles
- ⏳ Loading Spinner
- 🔄 Try Again button when news fails to load
- 🎨 Clean and Modern UI
- ⚡ Built with React.js

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap
- Vite
- Currents API
